# Blind Buy

A guessing game for fragrance people, in the style of the football-player guessing games. You get a fragrance's note pyramid, drawn as coloured bars grouped into top, heart and base, and a blurred photo of its bottle, and you guess which fragrance it is. Each guess is compared with the answer on ten traits. When the round ends, the bottle comes into focus.

The fragrances are the 250 most-voted on Fragrantica, with houses from the Gulf states left out.

| Trait | Green | Yellow | Arrow |
|---|---|---|---|
| Brand | same brand | | |
| Gender | same | one of them is unisex | |
| Country | same country of the house | | |
| Year | same year | within 4 years | newer / older |
| Rating | same Fragrantica rating | within 0.10 | higher / lower |
| Votes | (only the answer) | within 20% | more / fewer |
| Main accord | same first accord | it is in the answer's top 5 accords | |
| Accords | all 5 top accords shared | 2 or more shared | |
| Perfumer | same perfumer(s) | one perfumer shared | |
| Notes | correct bottle | at least one note shared (shared notes light up) | |

## Modes

- **Easy**: the 100 most-voted. All notes, gender and the top three accords shown. 10 guesses.
- **Medium**: the top 175. Half the notes start blurred and one unblurs after each miss. 8 guesses.
- **Hard**: all 250. Two notes to start, one more after each miss. 6 guesses.

Filter by **All / Men / Women / Unisex**. Each mode and filter has its own **Daily** bottle, plus **Unlimited** practice. Hidden notes keep their bar colour, so you can still tell a citrus from a wood. Hints: main accords, decade, country, perfumer, brand initial, gender and extra notes.

The hidden bottle is drawn on a canvas from a copy shrunk to a few pixels wide, and the sharp photo is only added to the page when the round ends, so it can't be dragged out or saved early. Blurred notes use stand-in text, so the real names aren't in the page source either.

## Run it

Static site, no build step. Open `index.html` or serve the folder (`npx serve .`).

## Data

`js/data.js` is generated by `scripts/build_data.py` from the public [Fragrantica.com Fragrance Dataset](https://www.kaggle.com/datasets/olgagmiufana1/fragrantica-com-fragrance-dataset) (`fra_cleaned.csv` and `fra_perfumes.csv`):

```
python3 scripts/build_data.py fra_cleaned.csv fra_perfumes.csv
```

It ranks fragrances by Fragrantica rating votes, drops Gulf houses, and keeps the top 250 with their notes, accords, rating, vote count, perfumers, year and Fragrantica id. Bottle photos load from Fragrantica's image host (`fimgs.net/mdimg/perfume/375x500.<id>.jpg`). The dataset is a snapshot, so vote counts and the ranking are from when it was scraped, not live.

## Site files

- `fonts/`: Geist and Instrument Serif, self-hosted (SIL Open Font License, licence files included), so the page makes no Google Fonts request.
- `og-image.png`: link preview image, original artwork.
- `404.html`, `robots.txt`: for static hosting such as GitHub Pages.

Once the site has a domain, add a `<link rel="canonical">`, make the `og:image` URL absolute, and add a `sitemap.xml`.
