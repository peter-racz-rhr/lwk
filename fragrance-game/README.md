# Blind Buy

A guessing game for fragrance people, in the style of the football-player guessing games. You get a fragrance's note pyramid, drawn as coloured bars grouped into top, heart and base, and a blurred photo of its bottle, and you guess which fragrance it is. Each guess is compared with the answer on ten traits. When the round ends, the bottle comes into focus.

The fragrances are the 500 most-voted on Fragrantica, with houses from the Gulf states left out.

| Trait | Green | Yellow | Arrow |
|---|---|---|---|
| Brand | same brand | | |
| Gender | same | one of them is unisex | |
| Country | same country of the house | | |
| Year | same year | within 4 years | newer / older |
| Rating | same Fragrantica rating | within 0.10 | higher / lower |
| Votes | (only the answer) | within 20% | more / fewer |
| Main accord | same first accord | it is in the answer's top 5 accords | |
| Accords | all 5 top accords shared | 2 or more shared | |
| Perfumer | same perfumer(s) | one perfumer shared | |
| Notes | correct bottle | at least one note shared (shared notes light up) | |

## Modes

- **Easy**: the 150 most-voted. Lightly blurred bottle; all notes, gender and the top three accords shown. 10 guesses.
- **Medium**: the top 300. Heavily blurred bottle; half the notes start blurred and one unblurs after each miss. 8 guesses.
- **Hard**: all 500. No bottle photo until the reveal; two notes to start, one more after each miss. 6 guesses.

Filter by **All / Men / Women / Unisex**. Each mode and filter has its own **Daily** bottle, plus **Unlimited** practice. Hidden notes keep their bar colour, so you can still tell a citrus from a wood. Hints: main accords, decade, country, perfumer, brand initial, gender and extra notes.

The hidden bottle is drawn on a canvas from a copy shrunk to a few pixels wide, and the sharp photo is only added to the page when the round ends, so it can't be dragged out or saved early. Blurred notes use stand-in text, so the real names aren't in the page source either.

## Run it

Static site, no build step. Open `index.html` or serve the folder (`npx serve .`).

## Data

`js/data.js` is generated by `scripts/build_data.py` from the public [Fragrantica.com Fragrance Dataset](https://www.kaggle.com/datasets/olgagmiufana1/fragrantica-com-fragrance-dataset) (`fra_cleaned.csv` and `fra_perfumes.csv`):

```
python3 scripts/build_data.py fra_cleaned.csv fra_perfumes.csv
```

It ranks fragrances by Fragrantica rating votes, drops Gulf houses, and keeps the top 500 with their notes, accords, rating, vote count, perfumers, year and Fragrantica id. Bottle photos load from Fragrantica's image host (`fimgs.net/mdimg/perfume/375x500.<id>.jpg`). The dataset is a snapshot, so vote counts and the ranking are from when it was scraped, not live.

## Site files

- `fonts/`: Geist and Instrument Serif, self-hosted (SIL Open Font License, licence files included), so the page makes no Google Fonts request.
- `og-image.png`: link preview image, original artwork.
- `404.html`, `robots.txt`: for static hosting such as GitHub Pages.

Once the site has a domain, add a `<link rel="canonical">`, make the `og:image` URL absolute, and add a `sitemap.xml`.

## Launch checklist

Before making the site public:

2. **Get Fragrantica's permission, or replace their content.** The notes, ratings and votes are a copy of Fragrantica's database, and the bottle photos are hotlinked from their image server. In the EU a database like that is protected by the sui generis database right, and product photos by copyright. A free fan game lowers the risk but does not remove it. Write to Fragrantica and ask; if they say no, swap the photos for ones you are licensed to use and rebuild the data from a source you may use.
3. **Have the legal pages checked** by a lawyer for your country. They are a starting point drafted from how the site actually works, not legal advice.
4. If you mainly target Hungarian players, add Hungarian versions of the three legal pages.
5. Once the domain is fixed, add `<link rel="canonical">`, make the `og:image` URL absolute, and add `sitemap.xml`.

## Security

- `_headers` sets a strict Content Security Policy (scripts, styles, fonts only from the site itself; images only from the site and fimgs.net), blocks framing, and turns off browser features the game doesn't use. Cloudflare Pages and Workers static assets both read it.
- No third-party scripts, no cookies, no forms, no server code.
- Everything shown from the data is escaped, and saved browser state is validated before use.
- Known, accepted limit: the answer has to live in the browser, so a player who opens developer tools can find it. That only spoils the game for themselves.

## Data corrections

`data/overrides.json` holds note pyramids that Fragrantica has updated since the Kaggle snapshot, each checked against the live page. `scripts/build_data.py` applies them and also merges spelling variants (vanille/vanilla, oak moss/oakmoss and similar) so shared notes match across bottles.
