| Skill | Invoke | What it does |
|---|---|---|
| grill-me | `/grill-me` | Relentless interview about a plan until every decision is settled. Calls `grilling`. |
| grilling | automatic | The interview engine behind grill-me: questions in rounds, each with a recommended answer. |
| diagnosing-bugs | `/diagnosing-bugs` or "debug this" | Build a failing feedback loop first, then minimise, hypothesise, instrument, fix, regression-test. |
| handoff | `/handoff` | Writes a handoff doc so a fresh agent session can pick up the work. |
